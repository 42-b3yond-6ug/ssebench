# Difficulty levels

::: info
This page is being written.
:::

This page will explain the five difficulty levels, from `FULL_ASSISTANCE` (0) to `NO_BUILD` (4): which checks the agent may run while it works at each level, why the default is `NO_FUTURE_TEST` (2), and how to compare results across levels. Final grading always runs every check the task has. The [MCP server reference](/reference/mcp-server#difficulty-levels) lists what each level enables.
