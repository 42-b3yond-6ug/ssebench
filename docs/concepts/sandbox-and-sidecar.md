# Sandbox and sidecar

::: info
This page is being written.
:::

This page will compare the two execution modes: sandbox, where the agent runs in the same container as the project, and sidecar, where the agent runs in its own container and reaches the project through a shared volume and the daemon. It will cover when to use each and the limits of sidecar mode, which is experimental. The [architecture overview](/concepts/architecture#running-modes) summarizes both.
