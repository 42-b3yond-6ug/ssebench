# How to contribute

Contributions are welcome: bug reports, fixes, new tasks, new agents and
documentation improvements.
[CONTRIBUTING.md](https://github.com/42-b3yond-6ug/ssebench/blob/main/CONTRIBUTING.md)
in the repository describes the development setup, the checks to run before
you open a pull request, and how pull requests are reviewed.

- Questions, bugs and feature requests go in GitHub issues.
- Report security problems, including any way for an agent to reach the
  reference answer, privately as described in the
  [security policy](https://github.com/42-b3yond-6ug/ssebench/blob/main/SECURITY.md).
- Everyone taking part is expected to follow the
  [Code of Conduct](https://github.com/42-b3yond-6ug/ssebench/blob/main/CODE_OF_CONDUCT.md).
