# Add a task

::: info
This page is being written.
:::

This guide will walk through adding a task to a dataset: the layout of a task folder, the fields of `sse/config.yaml`, the build, run and test scripts, the proofs of concept and reports, the reference patch and test diffs, and the dataset checks a new task must pass. Tasks must be publicly disclosed vulnerabilities with an upstream fix. See [Tasks and datasets](/concepts/tasks-and-datasets) for the concepts.
