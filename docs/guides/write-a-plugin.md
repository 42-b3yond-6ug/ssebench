This guide will walk through writing a plugin: the plugin folder and its `run.sh`, registering it in `plugins.yaml` with a hook, a timeout and whether it needs LLM access, and trying it on a pilot task. See [Plugins and hooks](/concepts/plugins-and-hooks) for how hooks run. To add a tool layer, a container mode or a CLI command instead, see [Extension points](/guides/extension-points).
