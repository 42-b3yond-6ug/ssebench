# datasets

| Directory | What it is |
|---|---|
| [`pilot/`](pilot/) | The pilot dataset: 55 tasks, one folder each, with `dataset.yaml`, the generated `manifest.json`, `third_party.json` and the `THIRD_PARTY.md` generated from it. |
| [`schema/`](schema/) | JSON Schemas of the task config, `dataset.yaml` and the manifest, generated by `uv run ssebench dataset schema`. |

Task material is licensed under CC BY 4.0, and the upstream code that tasks
include keeps its own licenses; see
[`pilot/LICENSE`](pilot/LICENSE) and [`pilot/THIRD_PARTY.md`](pilot/THIRD_PARTY.md).
Check a dataset with `uv run ssebench dataset validate`, and regenerate the
manifest after any change with `uv run ssebench dataset manifest`.
